# Music media vectors

Vendored Lucide SVGs: external-link, list-music, play, pause, skip-back, skip-forward,
library and house.
Source: https://github.com/lucide-icons/lucide/tree/main/icons
Retrieved 2026-11-10. ISC / Feather notices are included in LICENSE-lucide.txt.
The exact local SVGs are embedded by Rust and rasterized with resvg at device DPI.
No remote icon downloads or font glyph substitutions occur at runtime.
